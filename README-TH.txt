เว็บพอร์ตโฟลิโอ Flight Deck + ไอริ
=====================================

ไฟล์ในโฟลเดอร์นี้
  index.html   หน้าเว็บ (ไม่ต้องแก้ก็ได้)
  content.js   ข้อมูลทั้งหมดของคุณ ← แก้ไฟล์นี้ไฟล์เดียว
  images/      รูปทั้งหมด (airi.png มีให้แล้ว)


1) ใส่ข้อมูลของคุณ
  - เปิด content.js ใน VS Code
  - ข้อความใน [วงเล็บเหลี่ยม] คือตัวอย่าง ให้แก้เป็นของจริงแล้วลบวงเล็บออก
    (หน้าเว็บจะมีแถบสีส้มด้านบนบอกว่ายังเหลือกี่ช่อง พอแก้ครบแถบจะหายเอง)
  - { th: "...", en: "..." } = ภาษาไทย / อังกฤษ  ไม่อยากทำภาษาอังกฤษ ตั้ง bilingual: false
  - หัวข้อไหนไม่ใช้ ให้ลบรายการข้างในจนเหลือ [] หัวข้อนั้นจะหายไปเอง
  - การ์ดผลงานไอริเขียนจากของที่ทำจริงไว้ให้แล้ว อ่านแล้วแก้ให้ตรงกับที่คุณอยากเล่า


2) ใส่รูป (เอาไฟล์ไปวางในโฟลเดอร์ images ตั้งชื่อตามนี้ ไม่ต้องแก้โค้ด)
  profile.jpg            รูปหน้าตรงของคุณ (แนวตั้ง 3:4)
  activity-1.jpg, -2     รูปกิจกรรมในสมุดบันทึก
  gallery-1.jpg ถึง -3   รูปกิจกรรมเพิ่มเติม
  award-1.jpg ถึง -3     รูปเกียรติบัตร
  project-2.jpg          รูปผลงานที่ 2
  airi-project.jpg       (ไม่ใส่ก็ได้) รูปแทนไอริในการ์ดผลงาน
  airi.png               รูปไอริในกล่องถาม-ตอบ — อยากได้รูปใหม่ให้ใช้ PNG พื้นใส แล้วทับไฟล์เดิม
  มีรูปมากกว่านี้ = เพิ่มรายการใน content.js แล้วใส่ชื่อไฟล์ให้ตรง


3) ดูตัวอย่างในเครื่อง
  ดับเบิลคลิก index.html (ต้องต่อเน็ตเพื่อโหลดฟอนต์)
  หรือใน VS Code ติดตั้งส่วนขยาย Live Server แล้วคลิกขวา index.html → Open with Live Server


4) เอาขึ้นเว็บฟรีให้กรรมการเปิดได้ (เลือกวิธีเดียว)
  ก. GitHub Pages (ถาวร)
     สร้าง repository ใหม่บน github.com (Public) → Add file → Upload files
     ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ images) → Commit
     Settings → Pages → Source: Deploy from a branch → main → Save
     รอ 1–2 นาที จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/ชื่อrepo/
  ข. Netlify Drop (เร็วสุด)
     เข้า app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ไปวาง → ได้ลิงก์ทันที
     (ต้องสมัครบัญชีฟรีเพื่อให้ลิงก์อยู่ถาวร)
  ได้ลิงก์แล้วจะทำ QR code ใส่ในพอร์ต PDF ก็ได้


5) ไอริตอบยังไง
  ไอริตอบจากข้อมูลใน content.js เท่านั้น (ไม่ใช้ API key ไม่มีคีย์หลุด ไม่แต่งเรื่องเอง)
  ถามเรื่องที่ไม่มีข้อมูล ไอริจะบอกว่ายังไม่รู้ และชวนไปถามเรื่องอื่น
  เพิ่มคำถาม-คำตอบเองได้ที่ airi.faq ใน content.js
    q = คำที่ต้องมีในคำถาม (มีคำไหนก็ได้) · "ทำไม+สอบ" = ต้องมีทั้งสองคำ
    a = คำตอบ · goto = ปุ่มพาไปหัวข้อ (preflight / taxi / takeoff / climb / cruise / approach / landing)
  ปุ่มลำโพงในกล่องไอริ = ให้เบราว์เซอร์อ่านคำตอบออกเสียง (ใช้เสียงไทยของเครื่องคนดู)


ข้อควรระวัง
  - เว็บนี้ใครมีลิงก์ก็เปิดได้ อย่าใส่ที่อยู่บ้าน เลขบัตร หรือข้อมูลที่ไม่อยากให้คนอื่นเห็น
  - รูปไอริมาจากโมเดลที่คุณซื้อ ใช้ในพอร์ตส่วนตัวได้ แต่อย่าแจกไฟล์โมเดล
  - แสงห้องนักบิน NIGHT / DAY กับปุ่ม TH / EN อยู่มุมขวาบน เว็บจำค่าที่คนดูเลือกไว้ให้
